# Análise Exploratória de Dados

Aplicação web (React + Vite) para upload de bases de dados (CSV, TSV, Excel, JSON) e geração automática de relatórios de análise exploratória — diagnóstico de qualidade, estatísticas descritivas, correlações, testes de hipótese e dashboards. Todo o processamento acontece no navegador; nenhum dado é enviado a um servidor.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

Gera a pasta `dist/`, publicada automaticamente no GitHub Pages a cada push na branch `main` (veja `.github/workflows/deploy.yml`).
